# Contributing to Nitya Clinic - Hospital Appointment System

Welcome! We're excited that you're interested in contributing to the Nitya Clinic project. Your help can make this project even better!

## Ways to Contribute
There are several ways you can contribute:
- **Bug Reports**: If you find a bug, please open an issue and describe the problem.
- **Feature Ideas**: We welcome suggestions for new features! Share your ideas in an issue.
- **Documentation**: Help us improve the documentation by fixing typos or adding more details.
- **Code**: If you're comfortable with JavaScript, feel free to dive into the code and submit improvements or new features.

## Setting Up the Project Locally
To run the project on your local machine, follow these steps:

1. **Start the Backend** (required - stores appointment data):  
   Double-click **`start-backend.bat`** — OR run manually:
   ```bash
   cd backend
   npm start
   ```
   You should see: `Nitya Clinic Backend Started! http://localhost:8080`

2. **Open the Website**:  
   Double-click **`open-patient.bat`** — OR open `frontend/patient-login.html` in your browser.

## Submitting a Pull Request
To submit a pull request, please follow these steps:
1. **Fork the repository** on GitHub.
2. **Create a new branch** for your feature or fix.
3. **Commit your changes** with a clear message.
4. **Push your branch** to your forked repository.
5. **Open a pull request** against the main repository.

## Code Style
Please adhere to the existing code style in the project. Consistency helps maintain readability and quality.

Thank you for considering contributing to the Nitya Clinic project! Your contributions are greatly appreciated!
